# Token for Granted

A public guide to grant money for universities, researchers and non-profits: the routes to it (research project grants; fellowships, career and training awards; programme and service grants; capacity and infrastructure), the registrations and rules on each, how federal agencies and foundations decide, and an opportunity search built from public feeds.

Status: pre-build. The content pack is being written; this repo currently holds only the source-feed probe (`.github/workflows/probe-sources.yml`), which checks which public grant and foundation data feeds a GitHub Actions runner can reach, how big they are, and which of them a browser may call directly.

Not legal, tax or compliance advice. Every record links to its governing text. No affiliation with any university, non-profit, foundation or agency.

Sister site: [FAR Out](https://danieladamek.github.io/far-out/), for small businesses doing federal contract work.
